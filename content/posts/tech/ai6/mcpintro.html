Log Query MCP 使用说明

日志查询工具集成文档 · ClickHouse 日志平台 · 2026-05

工具概览

Log Query MCP 提供对 ClickHouse 日志平台的结构化查询能力，支持 Service 日志、Nginx 日志及全链路追踪三类场景。 所有查询结果以 Markdown 表格形式输出，禁止直接输出原始 JSON。

三个核心工具
  • query_service_logs — 查询服务日志（ERROR / WARN / INFO）
  • query_nginx_logs — 查询 Nginx 接入层日志
  • trace_request — 按 tracerId 同时查询 Service 和 Nginx 两张表，还原完整调用链
两种查询模式
  • structured（默认）：通过结构化参数构建 WHERE 条件，适合常规查询
  • custom：通过 custom_where 传入自定义 SQL 片段，适合复杂条件

整体架构与调用路径

Log Query MCP 基于 MCP（Model Context Protocol） 协议，将 AI 助手与 ClickHouse 日志平台打通。 整个链路分为三层：AI 对话层、MCP 工具层、数据存储层。

MCP 协议原理

MCP 是 Anthropic 提出的开放协议，让 AI 模型能够安全地调用外部工具。AI 不直接访问数据库， 而是通过标准化的工具描述（Tool Schema）声明能力，由 MCP Server 负责实际执行，结果再返回给 AI 处理。

① 工具注册

MCP Server 启动时向 AI 声明可用工具及参数 Schema

→
② 意图识别

AI 根据用户问题选择合适工具，自动填充参数

→
③ 工具执行

MCP Server 执行查询，AI 无法绕过 Server 直接访问 DB

→
④ 结果处理

AI 拿到结构化数据，按 skill 规范格式化后呈现给用户

两张核心日志表

Nginx 日志表
tq_log.ods_nginx_log_collection_all
  • 记录每一次 HTTP 请求的接入层信息
  • 包含 uri、token、responseTime、tracerId
  • 适合排查：接口是否被调用、响应时间、用户 token
Service 日志表
tq_log.ods_service_log_collection_all
  • 记录服务内部的应用日志（INFO / WARN / ERROR）
  • 包含 system、level、message、tracerId、k8s_pod_name
  • 适合排查：业务异常、代码报错、调用链路

工具参数说明

query_service_logs — Service 日志

参数类型说明备注
systemString服务名称（精确匹配）按服务查必用此字段
levelString日志级别：INFO / WARN / ERROR
messageString日志消息关键词（LIKE 模糊，≥ 3 字符）
tracerIdStringTracer ID（精确匹配）
envString环境，默认 test
time_startString开始时间，格式 YYYY-MM-DD HH:mm:ss不传默认最近 1 小时
time_endString结束时间，格式 YYYY-MM-DD HH:mm:ss不传默认当前时间
page / page_sizeNumber分页，page 从 1 开始
query_modeStringstructured（默认）或 custom
custom_whereString自定义 WHERE 片段，仅 custom 模式生效禁止写入操作
appcodeString应用码（数字形式，非服务名）不要用来按服务名查

query_nginx_logs — Nginx 日志

参数类型说明备注
uriString请求 URI（精确匹配）
client_uriString客户端 URI（精确匹配）
tokenStringToken（精确匹配）
systemString系统名称（精确匹配）
rt_gteNumber响应时间下限（毫秒，responseTime ≥ 该值）
queryString关键词模糊搜索（≥ 3 字符）
envString环境，默认 test
time_start / time_endString时间范围，格式 YYYY-MM-DD HH:mm:ss不传默认最近 1 小时
tracerIdStringTracer ID（精确匹配）

输出格式规范

MCP 工具返回 JSON，必须转换为 Markdown 表格输出，禁止直接输出原始 JSON。

摘要行

> 共 {total} 条，第 {page}/{pages} 页，耗时 {elapsed_ms}ms

表格列定义

列名内容格式说明
#行号跨页连续编号
时间YYYY-MM-DD HH:MM:SS取 time 字段
uri / client_uriclient_uri: {val} / uri: {val}
设备信息{appcode} | - | {platform} | - | - | {env} / token: {token}
其他内容{level} | {system} | {logOrigin} | {spanId} / tracerId: {tracerId}
日志内容{k8s_pod_name} | {env} | {serverIp} | {message 首行截 100 字}message 只取第一行，超 100 字截断
